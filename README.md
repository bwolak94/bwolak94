## 📐 Architecture Principles I follow

- **Composition over inheritance** — small, focused, reusable modules
- **Type-safety at every layer** — TypeScript from DB schema to UI props
- **Observability first** — structured logging, metrics, tracing from day one
- **Trunk-based development** — short-lived branches, fast CI, frequent deploys
- **DX matters** — if it's painful to onboard, the architecture has failed
